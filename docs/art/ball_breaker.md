# ТЗ: Ball Breaker — модель стенда (`rotp_spin:ball_breaker`)

Лор: ✅ визуализация энергии Спина от высшей бросковой техники семьи Цеппели
(`docs/spin-lore.md` → «Ball Breaker»; SBR гл. 83–84). Сенесценция — старение цели
в зоне касания. Сколотый шар = неполноценная манифестация (у нас уже есть флаг «повреждён»).

## Канон внешности (JoJo Wiki → Ball Breaker)
- Относительно небольшой, примерно с размер Стального шара; смутно гуманоидный, сутулый,
  копытообразные ступни.
- На лице — несколько кругов-«глаз» в случайном порядке; тело усыпано такими же точками.
- Главная примета: **широкий обод вокруг затылка, спереди заканчивается двумя полукружьями —
  обе образуют золотые спирали**.
- Аура: облако энергии как электростатические разряды.
- Палитра (цветная манга): тело лаймово-зелёное с тёмными вставками, узоры розовые/красные.
  ⚠️ Масштаб: в каноне стенд крошечный; для читаемости в бою делаем **0.9–1.0 от игрока**
  (⚠️ допущение, помечено).

## Процесс (строго по `docs/model-guide.md`)
1. Стартовать от `example_stand.geo.bbmodel` (ветка `new-model-anim-import`) — иерархию не ломать,
   пивоты в суставах. Сутулость — наклоном торса, а не сдвигом пивотов.
2. Этап 1 — блокинг: голова с ободом, сутулый торс, руки, короткие ноги с копытцами.
   Проверка чёрным силуэтом спереди/сбоку + скриншоты мне.
3. Этап 2 — посадка: T-pose + тестовая анимация взмаха; обод не отрывается от головы.
4. Этап 3 — детали текстурой (точки-«глаза», гравировка спиралей), кубов ≤ 60.

### Ориентиры размеров (1 блок = 16 юнитов, рост стенда ~30 юнитов)
| Часть | Примечание |
|---|---|
| Голова | ≈ 7×7×7, «глаза»-круги только текстурой |
| Обод | тонкое кольцо за затылком + 2 полукружья спереди, толщина ≤ 1 юнит |
| Торс | сутулый (наклон вперёд ~15°), уже плеч |
| Руки | длинные, кисти крупные (ударные) |
| Ноги | короткие, ступни-копытца 4×3×5 |

## Анимации (экспорт `.animation.json`, 20 тиков = 1 сек)
Обязательные: `idle` (2–4 с, бесшовный луп, лёгкое покачивание + дрожание разрядов),
`summon`, `dissipate`, `punch_light`, `punch_heavy`, `block`, `senescence_touch`
(касание с задержкой ладони на цели — момент старения). Удар = быстрый выпад + медленный возврат.

## Ремоделинг по референсам (v2)
Собрано по 5 референсам: манга-арт (голова с «глазами» на стебельках, шляпо-образные уши), арты Eyes of Heaven
(поза, ботинки-«ракеты», кисти), игровая T-pose-модель (пропорции). Исходник — `tools/gen_ball_breaker.py`.
- **Уши** — два круглых диска на стойках над головой (наклон ~30° вперёд и ~22° наружу), внутренняя сторона тёмная.
  ⚠️ Расхождение с ТЗ выше: на референсах это «мышиные» диски, а не обод с золотыми спиралями. Приоритет — референсы.
- **Силуэт**: узкая талия-«корсет», широкая грудь с зигзагами (текстурой), наплечники, тёмные «чешуйчатые» боковины
  бёдер/голеней/рук, длинные ноги, ботинки с раструбом и боковыми «плавниками», крупные кисти с пальцами.
- **Перед модели — `-Z`** (как в шаблоне; в прошлой версии носки были направлены назад).
- 52 куба, рост тела 36 юнитов (с ушами ~39). Иерархия костей и имена — как в `example_stand`; добавлены только
  `rightEar`/`leftEar` под `head_rot`. Пивоты: плечо y=27, локоть y=21, бедро y=16, колено y=9, шея y=30.
- Розовые «шляпки» — текстурой (плейсхолдер: 2×2 px, тёмная сетка — на боковинах). Анимации ещё не сделаны.
