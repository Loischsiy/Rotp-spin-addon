# RotP Spin Addon

Spin (JoJo's Bizarre Adventure Part 7/8) addon for [Ripples of the Past](https://github.com/StandoByte/Ripples-of-the-Past) — Minecraft 1.16.5, Forge 36.2.34.

- modid: `rotp_spin`
- Based on [RotP-Addon-example](https://github.com/StandoByte/RotP-Addon-example) by StandoByte.

## Build
Requires JDK 8.
```bash
./gradlew build
./gradlew test
./gradlew runClient
```
